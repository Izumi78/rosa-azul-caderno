# Rosa Azul Caderno

quero um site a tela inicial vai ter alguns quadradinhos representando como se bloco de notas com título e a descrição do que é, dentro dos blocos tenha uma pagina inteira para escrever, que tenha um espaço para colar links, um espaço que tenha uma ia especializada para me ajudar na organização, escrita e criação de gráficos e relatórios dentro do site. e também que tenha um mural onde possa interligar as páginas de bloco de notas que são criadas

como eu ia dizendo, um mural para interligar os blocos que tem assuntos que o conceito tem haver, que seja um site claro, com uma cor de folha mesmo tipo uma folha de gramatura amateigada, que o nome do site tenha alguma coisa haver com rosa azul, design do site agradavel, cores que podem ser usadas são roxo, preto, azul. que a navegação seja fluida, ao entra no bloco de notas tenha uma animação rápida.
